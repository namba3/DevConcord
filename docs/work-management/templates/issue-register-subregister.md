# サブ課題表

このファイルに記録した個別課題の状態・詳細・履歴・検証証拠の唯一の正本です。メイン課題表に索引登録し、この表ではプロジェクト全体の完成度評価や共通採番状態を重複管理しません。既存の状態・列・履歴がある場合は互換性を保ちます。詳細は[課題管理・完成度評価規約](../issue-tracking.md)を参照してください。
